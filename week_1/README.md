Objective
This project analyzes a real biological nucleotide sequence using basic Python concepts learned during Week 1.
The project is part of my weekly Python bioinformatics mini-task series.

#Sequence Source
The nucleotide sequence used in this project was obtained from the **NCBI Nucleotide Database**.
- **Organism:** Homo sapiens
- **Gene:** HBB (hemoglobin subunit beta)
- **Sequence type:** mRNA / nucleotide sequence
- **RefSeq accession:** NM_000518.5
- **Database:** NCBI Nucleotide

#Source:
https://www.ncbi.nlm.nih.gov/nuccore/NM_000518.5

#About the Sequence
HBB stands for **hemoglobin subunit beta**.
The HBB gene provides instructions for making the beta-globin protein, which is one of the protein subunits of hemoglobin. Hemoglobin is responsible for carrying oxygen in red blood cells.
The sequence used in this project is the **HBB mRNA RefSeq record NM_000518.5** from *Homo sapiens*.
The sequence is **628 nucleotides long** according to the NCBI record.

#Analysis Performed
The Python program:
- Displays the nucleotide sequence
- Calculates the sequence length
- Counts A, T, G and C nucleotides
- Calculates GC content
- Displays the first and last nucleotide
- Checks whether the sequence contains valid nucleotide bases
