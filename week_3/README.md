Week 3 — FASTA File Reader

Objective
Read a nucleotide sequence from a FASTA file and process it using Python.

-Analysis Performed
Reads the FASTA header and sequence.
Calculates sequence length.
Counts A, T, G, and C.
Calculates GC content as a percentage.

-Sequence Information/Input File
Organism: Homo sapiens
Gene: HBB — hemoglobin subunit beta
Sequence type: mRNA nucleotide reference sequence
NCBI RefSeq accession: NM_000518.5
Source: "NCBI Nucleotide — HBB" (https://www.ncbi.nlm.nih.gov/nuccore/NM_000518.5)

-Python Concepts Practised
File handling with "open()"
Reading lines using "readlines()"
Lists and string slicing
String methods: "strip()", "join()", and "count()"
Variables and arithmetic

-Files
"sequence.fasta" — input sequence.
"day15_fasta_reader.py" — analysis program.
"README.md" — project documentation.
