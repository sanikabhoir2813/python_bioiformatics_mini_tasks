Week 2 — Nucleotide Frequency Analyzer

Objective
Analyze a nucleotide sequence using Python data structures, loops, conditions, string slicing, and arithmetic.

Sequence Information
- Organism: Homo sapiens
- Gene: HBB — hemoglobin subunit beta
- Sequence type: mRNA nucleotide reference sequence
- NCBI RefSeq accession: NM_000518.5
- Source: "NCBI Nucleotide — HBB" (https://www.ncbi.nlm.nih.gov/nuccore/NM_000518.5)

Analysis Performed
- Calculates sequence length
- Counts A, T, G, and C
- Calculates GC content as a percentage
- Displays the first and last 10 bases

Python Concepts Practised
- Strings and slicing
- Variables and arithmetic
- "if / elif / else"
- "for" loops
- Counters
- Debugging

Files
- "day10_nucleotide_frequency.py" — main Python program
- "README.md" — project documentation

Learning Goal
Apply basic Python skills to analyze biological nucleotide data.
